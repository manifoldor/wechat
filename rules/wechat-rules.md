# 微信生态交互约束规则

在处理与微信（公众号、企业微信、微信客服）相关的任务或生成发送至微信的内容时，必须遵守以下准则：

1. **响应时效限制（5 秒生死线）**：
   - 微信服务器推送消息到 Webhook 时，严格要求 5 秒内返回 HTTP 200。
   - 禁止在单次同步 Webhook 回调中执行可能超时的重型任务。
   - 当检测到 Agent 思考或生成耗时可能超过 4.5 秒时，应立刻切断被动回复通道（返回空串或 `success`），转由后台异步客服接口（`cgi-bin/message/custom/send`）进行主动推送。

2. **内容长度与排版规范**：
   - 微信公众号文本消息单条最大容量为 2048 字节（UTF-8 编码下约 680 个汉字）。超长消息必须在发送前自动合理切分为多条。
   - 微信公众号不支持 Markdown 代码块与加粗符号（`**` 会原样显示），应使用换行、分段与空行增强可读性；支持超链接标签 `<a href="URL">文本</a>`。
   - 企业微信支持微信特有 Markdown 子集（支持 `### 标题`, `**加粗**`, `[链接](url)`, `` `代码` ``, `<font color="info">绿色</font>`, `<font color="comment">灰色</font>`, `<font color="warning">橙红色</font>`）。

3. **安全与隐私合规**：
   - 生产环境中必须启用安全模式（加解密），禁止明文传输。
   - 严格保护用户的 OpenID、UnionID 及手机号等敏感信息，禁止在日志中明文打印完整的密钥及用户个人敏感数据。
   - 每次接收微信请求前必须校验签名（`signature` 或 `msg_signature`），拒绝未授权或伪造的伪造请求。
